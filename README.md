# Dhanalaxmi Silver Luxe

Create a world-class premium luxury silver jewelry e-commerce website for a brand named "Dhanalaxmi Jeweler's".

The website should feel more premium than brands like Tanishq, CaratLane, and the reference website https://johaesilvers.in/, while keeping its own unique identity.

======================================================

BRAND STYLE

======================================================

Theme:

• Primary Background: Pure White (#FFFFFF)

• Secondary: Soft Light Gray (#F8F8F8)

• Text: Rich Black (#111111)

• Accent: Silver Metallic (#C0C0C0)

• Borders: Light Gray

• Buttons:

   Background Black

   Text White

   Hover → Metallic Silver
